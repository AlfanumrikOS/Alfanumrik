# 08 — Consolidation & Build Plan (for Gate-1 approval)

Ordering follows the brief: P0 data/security/content → single shell + tokens → global search + one nav model → role surfaces (super admin → school admin → teacher → parent → student) → bulk import/export → public site & SEO → polish. Every step retires its legacy surface in the same change; there is never a period with two live implementations of one concern. Host: Vercel only (the AWS host is decommissioned; steps therefore state "Vercel + Supabase" and confirm env/secret parity for Supabase Edge secrets where touched). Effort is engineer-days for one senior engineer; "verification" lists the exact commands or queries that must pass before the step's End-of-Change report (the CLAUDE.md "Compact Report Format") is emitted.
