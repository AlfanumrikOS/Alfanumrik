## Test Infrastructure Gaps Surfaced During Research (not packet-specific)

- **No committed eval reports for the RAG harness** — `eval/rag/reports/` is gitignored, so historical comparisons rely on prose, not reproducible data. Recommend un-gitignoring or otherwise persisting run history (flagged in Packet 3).
- **Two RAG eval harnesses exist** (`eval/rag/harness/` vs `scripts/rag-eval.mjs`+`eval/rag/runner.ts`) measuring different things — a naming/documentation gap that risks future confusion about which numbers mean what.
- **`.github/workflows/rag-eval.yml` is advisory-only** (`continue-on-error: true`) — the binary pass/fail scope-correctness harness doesn't block merges even when it fails.
- **Queue-consumer claim-step locking has no test either confirming or denying atomicity** — flagged as UNKNOWN in `21-dependency-graph-and-reclassified-risks.md` §B8; a targeted concurrency test (two consumers racing to claim the same row) would resolve this ambiguity and should be considered part of closing that UNKNOWN, even though it isn't one of the 12 launch-blocking packets.
